أنا مذيع - نسخة ويندوز المرتبة (نسخة Qt الأحدث، 7 تحديات)
=====================================================

التشغيل:
    python ana_modhi_qt.py

المتطلبات:
    pip install PyQt6      (أو PySide6)
    pip install faster-whisper   (لتفريغ تسجيل الطفل وعدّ الكلمات)

محتويات الحزمة:
    ana_modhi_qt.py   الواجهة الكاملة (نقطة التشغيل)
    ana_data.py       النصوص والبيانات المشتركة
    ana_recorder.py   التسجيل من الميكروفون (winmm)
    ana_stt.py        التفريغ العربي وعدّ الكلمات
    stt_worker.py     عامل التفريغ المنفصل (بيئة بايثون مستقلة،
                      يتوقعه ana_stt.py بجانبه)
    assets/audio/     المؤثرات الصوتية الثمانية
    assets/png/       (فارغة حالياً: الأيقونات اختيارية والبرنامج يعمل بدونها)

اكتملت الحزمة: كل الملفات التي يحتاجها الكود موجودة الآن.

ملاحظة: النسخة القديمة بواجهة Tkinter (ana_modhi.py) استُبعدت عمداً،
والعمل على نسخة Qt فقط حسب قرار شيرين بتاريخ 2026-11-20.
